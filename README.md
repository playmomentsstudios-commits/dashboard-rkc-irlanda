
  # KALUNGA Dashboard Design

  This is a code bundle for KALUNGA Dashboard Design. The original project is available at https://www.figma.com/design/hSCTgmtFpz6u5yj6EQQJRr/KALUNGA-Dashboard-Design.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
  


## Deploy institucional

URL final recomendada:
https://transparencia.kalungacomunicacoes.org/embaixada-irlanda

### Publicação

1. Subir projeto no GitHub
2. Conectar repositório na Vercel
3. Configurar domínio na Hostinger
4. Apontar:
transparencia.kalungacomunicacoes.org

### Comandos

Instalar dependências:
npm install

Rodar local:
npm run dev

Build produção:
npm run build
